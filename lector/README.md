# Lector WordPress Theme

Thank you for choosing Lector, a professional WordPress theme for educational content hubs. This document provides instructions on how to install and configure the theme.

## Installation

1.  **Download the Theme:** Download the `lector.zip` file.
2.  **Log in to WordPress:** Log in to your WordPress admin panel.
3.  **Navigate to Themes:** Go to `Appearance > Themes`.
4.  **Add New Theme:** Click the `Add New` button at the top of the page, then click `Upload Theme`.
5.  **Upload and Install:** Choose the `lector.zip` file you downloaded and click `Install Now`.
6.  **Activate the Theme:** Once the installation is complete, click the `Activate` link.

## Theme Options

The theme includes a simple options panel to help you customize your site.

1.  **Go to the Theme Options Page:** After activating the theme, navigate to `Appearance > Theme Options` in your WordPress admin menu.
2.  **Customize Settings:** You can currently customize the following:
    *   **Footer Copyright Text:** The text that appears in the footer of your site.
3.  **Save Changes:** Click the `Save Changes` button to apply your modifications.

Thank you for using the Lector theme!
